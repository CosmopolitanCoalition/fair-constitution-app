## Confirmed source defects and concrete evidence

### 1. The simulator seats board members but omits chair elections

`app/Services/Demo/SimBoardService.php` seats CGC governors and business/organization representatives, creates terms, and activates boards without invoking the chair-election pipeline. The existing `app/Services/Organizations/OrgBoardService.php::openChairElection` and `resolveChairVote` provide the real full-board ranked-choice election and record the resulting chair.

Leaf jurisdiction `2f31238b-43ac-487a-8014-1ad5dd841f93` has legislature 14/14, an appointed 5/5 court, and seated department governors. Its only gap is two unfilled chairs. Both CGC board `01a0bd8e-8965-70fa-9fc7-3b86c4f8acdc` and business board `01a0bd8e-89be-70e5-bf22-7df73eac8436` have all three members seated but `chair_seat_id=NULL`.

**Fix:** complete the real board election path with the correct electorate, consent, public records and audit effects. Repair existing boards too: `seedBusinessBoards` selects `whereNull(board_id)`, so simply replaying that generator misses already-created chairless boards. Reuse or safely resume an existing unfinished vote; do not create a new vote on every retry or directly assign a chair. A successful chair-only repair could clear bucket A's current findings, subject to re-verification.

### 2. Executive delegation rejects exactly five when the real service allows five

`GovernanceStage::growDepartments` checks `serving->count() <= EXEC_COMMITTEE_SIZE` where the size is five. `ExecutiveFormationService::assertDelegationSize` permits a committee of at least five that does not exceed serving members. Therefore five serving members can delegate five, but the simulator skips them.

The prerequisite census confirms **all 112,306 bucket B scopes are seated 5/5** and carry this exact skip. Example: `000032b7-dc88-4ac8-9edd-3dfdf92630aa`.

**Fix:** align the simulation guard with the service's valid boundary (five is permitted), then file and vote the existing F-LEG-014 act. Retain every underlying authority, composition and voting check. Continue missing department charters/governor consents and dependent civic work using their existing paths. Do not directly set executive status. Test 4/5/6 serving-member boundaries with the real service, including successful five-member adoption.

### 3. Bicameral guards compare uppercase `B` with persisted lowercase `b`

`GovernanceStage.php:304` and `JudiciaryStage.php:82` test `(string) $m->seat_type === 'B'`. `CertificationService` writes `'a'/'b'`; `LegislatureMember::SEAT_KIND_MAP` and `seatKind()` establish the same representation.

This is proven independently of missing election seats:

- Scope `1c9e2a01-d2b7-43c0-a9ee-d9c1baeb0629`: all **324/324** elected, including **162 lowercase-b** members; committees/courts incorrectly skipped as missing the Type B half.
- Scope `36542893-dac7-4a71-bbba-6efb4813d3fb`: all **22/22** elected, including **10 lowercase-b** members; same false skip.
- All **21,467** court-gap scopes with a legislative majority (buckets C+E) carry the Type B skip. Live member-type confirmation is bounded to the examples; repair preflight must still validate each current roster.

**Fix:** use the model's canonical seat-kind representation in both guards. Preserve the deferral for genuinely unseated halves. Replay only omitted committee and judiciary acts, reusing already-filed creations/nominations/consent votes and terms. Tests must use the actual lowercase persisted values; the current Phase8Performance fixture inserts uppercase `A` and does not exercise a seated bicameral boundary.

### 4. Per-scope candidate selection silently loses election-wide duplicates

`ElectionStage::fieldCandidates` draws ordered residents separately per race scope. Ancestor and descendant residency rosters overlap. Its per-scope cursor does not prevent cross-scope reuse. The source explicitly relies on `insertOrIgnore` to discard duplicates under the live unique index `candidacies_election_id_user_id_unique` on `(election_id,user_id)`, and reports planned `count($rows)` instead of persisted counts.

Earth scope `27cf7c64-2c76-4fd5-8544-bfd223cfdc72`, election `01a0b9a2-f736-723c-9a83-0b66a40417c2`:

- Reported **3,667** candidates across **514** races; actual candidacies **2,610**, a **1,057** shortfall.
- **90** races have no candidates and remained uncounted. Counting settled DONE with 424 counted/90 skipped. Seating settled DONE with `certified=false,seated=0` and “90 of 514 races not yet counted”. Governance and courts then skipped. Verification finds **0/3,153** legislators.
- In two Canadian five-seat races, all 12 ordered residents intended for those slots were already assigned to Earth-scoped races in the same election. Both Canadian races have zero candidacies despite a positive electorate. The collision mechanism is confirmed, not inferred only from a missing total.

**Fix:** stable election-wide assignment of unique eligible residents, preserving per-race residency, population ceilings and resumability. Use bounded roster refill/exclusions; protect existing assignments on retry and concurrent work. Report actual inserted/existing totals and validate each race's coverage. First inventory both empty races and partially filled races, including already-certified elections; the 15,338 unseated-government count is not the full count of elections potentially affected.
