# Education and achievement checks

Checked 2026-09-13, with the caption and media-feedback repair completed later in the same pass. This is an evidence record, not the build punch list. No live world data, civic acts, training completions, publication acts or external media were changed. Tests below used pure code/configuration checks or an in-memory fake media transport. The live Postgres test helpers were not invoked.

| Question | Verified result |
|---|---|

## Remaining internal checks, not punch-list build items

- Run a small isolated lesson journey: guest reading, failed quiz, passing quiz, repeat pass, progress latch and once-only training award/stipend. The existing `LearnPagesTest` and acceptance half of `EducationFormsTest` explicitly use `LivePgConnection`; they were inspected but not executed against the operator's world.
- Exercise person-profile achievement visibility and `/achievements` through separate simulated authenticated contexts. Existing `PersonProfileTest` and `AchievementsPageTest` use live Postgres. Code establishes that the surfaces exist; a new isolated browser/HTTP pass must establish the behavior.
- Run real browser media decoding against controlled local test assets: play/pause/seek, language switch during playback, master ending, buffering, network failure, caption timing and remembered preferences. These are automatable and are not human-only deferrals.
- Recheck current instructional text against completed actions after consolidation. The successful ID coverage scan alone cannot establish semantic currency, translation quality or accessibility.
- Inventory explicit non-V2 layouts and give setup/operator education an appropriate home. The bare setup/auth layouts and legacy operations/dev kits are known exceptions to the shared flyout. This audit does not assume that an identical floating bar is appropriate on every setup screen.

Only human judgment of explanation quality, naturalness of translations, comprehension and physical-device experience belongs in the human-deferred record. Missing internal evidence stays in the internal check register.
